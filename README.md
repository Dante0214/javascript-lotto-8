🎯 3주 차 미션 - 로또

## 기능 목록

### 1. 입력 기능

- [x] 로또 구입 금액을 입력받는다.

  - [x] [예외] 입력값이 숫자가 아닌 경우 [ERROR]로 시작하는 에러 메시지를 출력한다.

  - [x] [예외] 입력값이 1,000원 단위가 아닌 경우 [ERROR]로 시작하는 에러 메시지를 출력한다.

  - [x] [예외] 입력값이 0 이하인 경우 [ERROR]로 시작하는 에러 메시지를 출력한다.

- [ ] 당첨 번호 6개를 쉼표(,)로 구분하여 입력받는다.

  - [ ] [예외] 쉼표(,) 기준으로 6개가 아닌 경우 [ERROR] 에러 메시지를 출력한다.

  - [ ] [예외] 각 번호가 1~45 사이의 숫자가 아닌 경우 [ERROR] 에러 메시지를 출력한다.

  - [ ] [예외] 중복된 숫자가 있는 경우 [ERROR] 에러 메시지를 출력한다.

- [ ] 보너스 번호 1개를 입력받는다.

  - [ ] [예외] 1~45 사이의 숫자가 아닌 경우 [ERROR] 에러 메시지를 출력한다.

  - [ ] [예외] 당첨 번호와 중복된 숫자인 경우 [ERROR] 에러 메시지를 출력한다.

- [ ] [공통] 모든 입력 예외 발생 시, 해당 부분부터 입력을 다시 받는다.

### 2. 로또 발행 기능

- [x]구입 금액에 따라 로또를 발행한다.
- [x] 1,000원당 1장의 로또를 발행한다.
- [x] 발행된 로또 수량을 출력한다.
- [x] 로또 번호를 생성한다.
- [x] 1~45 범위의 숫자 중 6개를 무작위로 선택한다.
- [x] 중복되지 않는 숫자를 선택한다.
- [x] 생성된 번호를 오름차순으로 정렬하여 출력한다.

### 3. 당첨 비교 및 통계 계산 기능

- [ ]구매한 로또와 당첨 번호를 비교한다.
- [ ] 일치하는 번호의 개수를 확인한다.
- [ ] 보너스 번호 일치 여부를 확인한다.
- [ ] 당첨 등수를 판단한다.
  - [ ] 6개 일치: 1등 (2,000,000,000원)
  - [ ] 5개 일치 + 보너스 일치: 2등 (30,000,000원)
  - [ ] 5개 일치: 3등 (1,500,000원)
  - [ ] 4개 일치: 4등 (50,000원)
  - [ ] 3개 일치: 5등 (5,000원)
  - [ ] 2개 이하 일치: 낙첨

### 4. 출력 기능

- [ ] 발행한 로또 수량을 출력한다. (예: 8개를 구매했습니다.)

- [ ] 발행한 로또 번호(오름차순 정렬) 목록을 모두 출력한다.

- [ ] '당첨 통계' 헤더를 출력한다.

- [ ] 당첨 내역을 정해진 형식에 맞게 출력한다.

- [ ] 3개 일치 (5,000원) - 1개

- [ ] 4개 일치 (50,000원) - 0개

- [ ] 5개 일치 (1,500,000원) - 0개

- [ ] 5개 일치, 보너스 볼 일치 (30,000,000원) - 0개

- [ ] 6개 일치 (2,000,000,000원) - 0개

- [ ] 총 수익률을 정해진 형식에 맞게 출력한다. (예: 총 수익률은 62.5%입니다.)

- [ ] 예외 발생 시 [ERROR]로 시작하는 에러 메시지를 출력한다.

6. 테스트

- [ ] Lotto 클래스에 대한 단위 테스트

- [ ] 로또 구입 금액 유효성 검사 기능에 대한 단위 테스트

- [ ] 당첨 번호 유효성 검사 기능에 대한 단위 테스트

- [ ] 보너스 번호 유효성 검사 기능에 대한 단위 테스트

- [ ] 당첨 등수를 결정하는 로직에 대한 단위 테스트

- [ ] 수익률을 계산하는 로직에 대한 단위 테스트
